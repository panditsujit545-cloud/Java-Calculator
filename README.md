# Java Calculator

A simple calculator made using Java.

## Features

* Addition, subtraction, multiplication
* Division and modulus
* Power and square root
* Calculation history
* Clear history
* Exception handling
* Input validation

## Technologies

* Java
* OOP
* ArrayList
* Exception Handling

## How to Run

```bash
javac Cal.java Calculator.java
java Cal
```

## Files

* `Cal.java` - Main program and user input
* `Calculator.java` - Calculator operations
